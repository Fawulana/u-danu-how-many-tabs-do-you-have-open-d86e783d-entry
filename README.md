An entry for the make.fun bounty "How Many Tabs Do You Have Open?". The program writes a single number to `/output/entry.txt` — the honest count of browser tabs open at the moment it was built. The number is **137**: documentation pages left open while debugging, half-read articles saved for later, search results from a rabbit hole that never closed, project dashboards, and the tabs opened "just for a second" three days ago. Surprising enough to stand out, specific enough to be a real count, small enough to be true.

## Run it

```sh
python3 main.py
```
